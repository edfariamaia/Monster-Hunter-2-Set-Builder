# Monster Hunter 2 Set Builder

An unofficial fan tool for **Monster Hunter 2 (Dos)**, the Japan-only PS2 game.

- Build up to 5 named sets (weapon plus 5 armor pieces), pick the target level of each piece, and socket decorations into their slots.
- See the set's total attack, element, defense, resistances, skill points and **active skills**.
- Get every material the set needs, with a "have / left" counter.
- Look up any weapon, armor piece, decoration or item: stats, skills, materials per level and in total, and where to get each material (carves, quest rewards, gathering spots by season, combinations, shops, Veggie Elder trades).
- Plan up to 5 item bags of 20 spaces, with each item's carry limit.

Everything runs in the browser from a single `index.html`. There is no server and no login. Each visitor's sets and bags are saved only in their own browser.
